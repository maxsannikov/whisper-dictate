## [Unreleased] — 2026-10-23

### Cloudflare и статус обработки

- Tray показывает один значок для Cloudflare, GPU или CPU; сводка расхода
  Workers AI начинается с оценочного числа нейронов и сохраняет разбивку.
- Daemon учитывает legacy Cloudflare ASR toggle, ограничивает Cloudflare
  correction live dictation и освобождает локальные модели перед удалёнными
  стадиями; ошибки переключаются на локальные fallback-модели.

## [1.2.0-local] — 2026-10-20

### Улучшения локальной диктовки

- Один последовательный worker daemon и `asyncio.to_thread` для ASR: один
  экземпляр модели не используется конкурентно.
- Строгий конфиг `~/.config/whisper-dictate/config.json` с baseline
  `large-v3`, `ru`, CUDA `int8_float16`, beam 1 и PTT без VAD.
- `local_files_only=True`; локальные cached-модели не должны инициировать
  загрузку из сети.
- Фактические device/compute type передаются daemon-ом клиенту; добавлены
  приватные JSONL-метрики без текста диктовки.
- `wl-copy` — основной результат в Wayland; прямая запись в Klipper SQLite
  исключена из нового маршрута.
- `large-v3-turbo` доступен только как экспериментальный A/B-профиль.
- Добавлен opt-in локальный Ollama-корректор: один последовательный запрос,
  timeout и безопасный возврат к исходному ASR-тексту. `qwen3.5:4b-q4_K_M`
  работает с измеренным частичным GPU-offload (8 слоёв), либо CPU по выбору.
- Добавлены Turbo launcher и отдельная горячая клавиша, tray-переключатель Turbo,
  выбор Qwen-корректора, CPU/GPU, видимая VRAM, выгрузка Qwen и редактируемый
  prompt. Prompt запрещает добавлять новые кавычки или «ёлочки» вокруг текста.

### Резервирование

## [1.1.0] — 2026-08-01

### ✨ Новое
- **YouTube-интеграция**: скачивание и распознавание видео с YouTube
  - Многострочный диалог ввода для YouTube-ссылок
  - Поддержка форматов: youtube.com, youtu.be, shorts, embed
  - Асинхронное скачивание с показом прогресса
  - Интеграция с batch-системой транскрибации
  - Автоматическое кэширование скачанного аудио
  - Ссылки на источники в результатах (txt/json/html)

### 🔧 Улучшения
- Система парсинга URL полностью защищена от injection
- Классификация ошибок yt-dlp (видео удалено, приватное, geo и т.д.)

- Отзывчивый UI без зависаний даже при скачивании часовых видео

### 📦 Зависимости
- Добавлен `yt-dlp` (опциональный, рекомендуемый)
- Минимальная версия: 2024.01+

### 🐛 Исправления
- Исправлена утечка временных файлов при отмене batch (Фаза 7)

## [1.0.0] — 2026-07-06

### 🎉 Initial Release

**Добавлено:**
- ✅ `install.sh` — автоматическая установка со всеми проверками
- ✅ `uninstall.sh` — безопасное удаление с подтверждением
- ✅ `verification/check-installation.sh` — полная проверка системы
- ✅ `verification/test-simple.sh` — простой тест транскрибации
- ✅ `INSTALL.md` — подробная инструкция для конечного пользователя
- ✅ `REQUIREMENTS.md` — полный список зависимостей
- ✅ `systemd/README.md` — управление демоном

**Компоненты:**
- `whisper-daemon.py` (v1.0) — AsyncIO сервер обработки
- `whisper-tray.py` (4.6 Final) — GTK3 трей-иконка
- `whisper-dictate-v2` (4.6 Final) — главный скрипт вставки
- `whisper-dictate-{fast,medium,full}-v2` — предустановки качества
- systemd units для демона и трея

**Особенности:**
- 🔧 Автоматическая проверка зависимостей
- 🐍 Поддержка Python 3.8+
- ⚡ GPU ускорение (NVIDIA CUDA)
- 🔄 Автозапуск и перезагрузка при крахе
- 📊 Логирование через systemd journal
- 🎯 Интеграция с KDE Plasma (трей, меню)

**Известные ограничения:**
- Локальное хранилище (GitHub синхр. не включена)
- Только OpenSUSE/Linux (Windows/macOS не поддерживаются)
- NVIDIA GPU поддержка (AMD/Intel требуют дополнительной настройки)

### 📚 Документация
- Инструкция установки (INSTALL.md)
- Список требований (REQUIREMENTS.md)
- Управление systemd (systemd/README.md)

## Версионизация

Используется **SemVer** (Semantic Versioning):
- **Major** (1.x → 2.0): Выпуск с большими изменениями
- **Minor** (1.0 → 1.1): Новые функции, совместимые
- **Patch** (1.0.0 → 1.0.1): Исправления багов

Примеры:
- `1.0` — Первый стабильный выпуск
- `1.1` — Добавлены новые функции
- `1.0.1` — Исправлена ошибка в 1.0
